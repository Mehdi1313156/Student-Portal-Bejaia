# Student Portal — Université de Béjaïa

A responsive, standalone student-portal **demo** with three sections:
- Accueil: quick-access university service tiles.
- Ma carte: a decorative, clearly marked non-official student-card mockup.
- Paramètres: edit the displayed name, birth date, major, academic year, and profile photo.

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Data and privacy
Profile settings are stored in the browser's localStorage on the current device. No backend or university account connection is implemented.

## Important
This is an independent demonstration UI. It is not affiliated with, connected to, or endorsed by Université de Béjaïa or PROGRES. The card preview is marked **MAQUETTE — NON OFFICIELLE** and is not valid proof of identity, enrollment, or student status.
